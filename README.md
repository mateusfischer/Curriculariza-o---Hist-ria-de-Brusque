Brusque Quiz: Jornada Histórica

Um jogo educativo desenvolvido em Java que utiliza uma interface visual para testar conhecimentos sobre a cidade de Brusque, Santa Catarina. O projeto foca em uma experiência de aprendizado guiada, onde cada erro é uma oportunidade de descobrir um novo fato histórico.

O Jogo

O quiz consiste em 15 perguntas desafiadoras sobre a fundação, cultura, economia e geografia de Brusque.
